## Acceptance Criteria

**BL-01**
- สแกน QR code แล้วเปิดเมนูตรงโต๊ะได้ทันทีบนเบราว์เซอร์มือถือ โดยไม่ต้องติดตั้งแอป
- ระบบระบุหมายเลขโต๊ะถูกต้องตาม QR code ที่สแกน

**BL-02**
- เมนูแสดงชื่อสินค้า รูปภาพ ราคา และตัวเลือก (ขนาด/ความหวาน/ชนิดนม) ครบทุกรายการ

**BL-03**
- เพิ่ม/ลบ/ปรับจำนวนสินค้าในตะกร้าได้ก่อนกดยืนยันคำสั่งซื้อ
- ตะกร้าคำนวณราคารวมถูกต้องตามตัวเลือกที่เลือก

**BL-04**
- คำสั่งซื้อที่ยืนยันแล้วมีหมายเลขโต๊ะแนบไปด้วยเสมอ
- ลูกค้าไม่สามารถแก้ไขคำสั่งซื้อเองได้หลังยืนยัน (ตาม Business Rule)

**BL-05**
- ออเดอร์ใหม่ปรากฏฝั่งร้าน/บาริสต้าแบบเรียลไทม์ ไม่ต้องรีเฟรชหน้าจอเอง

**BL-06**
- ลูกค้าเห็นสถานะออเดอร์อัปเดตอย่างน้อย 3 สถานะ: รับออเดอร์แล้ว / กำลังทำ / เสร็จแล้ว

**BL-07**
- หน้าเมนูมีลิงก์ "ประกาศความเป็นส่วนตัว" ที่เข้าถึงได้ก่อนกดยืนยันคำสั่งซื้อครั้งแรก
- เนื้อหา Privacy Notice ระบุอย่างน้อย: ข้อมูลที่เก็บ (หมายเลขโต๊ะ/รายการสั่งซื้อ/session/device identifier), วัตถุประสงค์, ฐานทางกฎหมายที่ใช้ (contract/legitimate interest), ระยะเวลาเก็บ, และช่องทางติดต่อเพื่อใช้สิทธิ
- ไม่มีการบังคับให้ลูกค้ากด "ยอมรับ" ก่อนสั่งซื้อ (เพราะไม่ได้ใช้ฐาน consent) แต่ต้องเข้าถึงลิงก์ได้ง่ายจากหน้าเมนู

**BL-08**
- ทุก request ระหว่างมือถือลูกค้า ระบบหลังบ้าน และหน้าจอบาริสต้า วิ่งผ่าน HTTPS/TLS เท่านั้น
- ระบบไม่บันทึกข้อมูลระบุตัวตนที่ไม่จำเป็น เช่น ไม่มีช่องเก็บชื่อ-เบอร์โทรของลูกค้าในฐานข้อมูลออเดอร์
- สิทธิ์การเข้าถึงข้อมูลออเดอร์/session ถูกจำกัดตาม role ของพนักงาน/ระบบที่จำเป็นต้องใช้เท่านั้น (ตรวจสอบผ่าน access control list หรือ role-based permission)

**BL-09**
- มีกระบวนการ/job ลบหรือ anonymize session/device identifier ภายในระยะเวลาที่กำหนด (ตามสมมติฐานในเอกสาร requirement เช่น ไม่เกิน 24 ชั่วโมงหลังปิดรอบโต๊ะ)
- ประวัติคำสั่งซื้อที่เก็บไว้เกินระยะเวลาที่กำหนด (เช่น เกิน 2 ปี) ถูกลบหรือทำให้ไม่สามารถเชื่อมโยงกลับไปหาลูกค้าคนหนึ่งได้อีก
- มีการบันทึก log ว่าได้ดำเนินการลบ/anonymize ตามรอบเวลาที่กำหนดจริง

**BL-10**
- Privacy Notice หรือหน้าเมนูระบุช่องทางติดต่อร้าน (เช่น แจ้งพนักงานหน้าร้าน หรือช่องทางที่ระบุไว้) สำหรับขอเข้าถึง/ขอสำเนา/ขอลบ/คัดค้านการใช้ข้อมูล
- มีขั้นตอนภายในร้าน (แม้เป็น manual process) รองรับคำขอใช้สิทธิของลูกค้าได้ภายในระยะเวลาที่เหมาะสม
