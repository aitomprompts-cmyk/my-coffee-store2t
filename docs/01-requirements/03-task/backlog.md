## Acceptance Criteria

**BL-01**
- สแกน QR code แล้วเปิดเมนูตรงโต๊ะได้ทันทีบนเบราว์เซอร์มือถือ โดยไม่ต้องติดตั้งแอป
- ระบบระบุหมายเลขโต๊ะถูกต้องตาม QR code ที่สแกน

**BL-02**
- เมนูแสดงชื่อสินค้า รูปภาพ ราคา และตัวเลือก (ขนาด/ความหวาน/ชนิดนม) ครบทุกรายการ

**BL-03**
- เพิ่ม/ลบ/ปรับจำนวนสินค้าในตะกร้าได้ก่อนกดยืนยันคำสั่งซื้อ
- ตะกร้าคำนวณราคารวมถูกต้องตามตัวเลือกที่เลือก

**BL-04**
- คำสั่งซื้อที่ยืนยันแล้วมีหมายเลขโต๊ะแนบไปด้วยเสมอ
- ลูกค้าไม่สามารถแก้ไขคำสั่งซื้อเองได้หลังยืนยัน (ตาม Business Rule)

**BL-05**
- ออเดอร์ใหม่ปรากฏฝั่งร้าน/บาริสต้าแบบเรียลไทม์ ไม่ต้องรีเฟรชหน้าจอเอง

**BL-06**
- ลูกค้าเห็นสถานะออเดอร์อัปเดตอย่างน้อย 3 สถานะ: รับออเดอร์แล้ว / กำลังทำ / เสร็จแล้ว
