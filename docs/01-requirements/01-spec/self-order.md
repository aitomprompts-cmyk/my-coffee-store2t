# Requirement: สั่งกาแฟผ่านมือถือที่โต๊ะ (Self-Order)

## ภาพรวม (Feature / User Story)

ลูกค้าที่นั่งอยู่ที่โต๊ะในร้าน สามารถสแกน QR code บนโต๊ะเพื่อเปิดเมนูบนมือถือของตัวเอง เลือกสั่งกาแฟ/เครื่องดื่ม และยืนยันคำสั่งซื้อได้เอง โดยไม่ต้องเรียกพนักงานมารับออเดอร์

## Functional Requirements

- ลูกค้าสแกน QR code ที่ติดอยู่บนโต๊ะเพื่อเปิดเมนูผ่านเว็บเบราว์เซอร์บนมือถือ (ไม่ต้องติดตั้งแอป)
- ระบบระบุหมายเลขโต๊ะโดยอัตโนมัติจาก QR code ที่สแกน
- ระบบแสดงเมนูเครื่องดื่ม พร้อมชื่อ รูปภาพ ราคา และตัวเลือก (เช่น ขนาด, ระดับความหวาน, ชนิดนม)
- ลูกค้าเลือกสินค้า ใส่ตะกร้า ปรับจำนวน และแก้ไข/ลบรายการในตะกร้าได้ก่อนยืนยัน
- ลูกค้ายืนยันคำสั่งซื้อพร้อมหมายเลขโต๊ะ โดยไม่ต้องเรียกพนักงาน
- ระบบส่งคำสั่งซื้อไปยังฝั่งร้าน/บาริสต้าแบบเรียลไทม์เพื่อเตรียมเครื่องดื่ม
- ลูกค้าสามารถดูสถานะคำสั่งซื้อของตนเอง (เช่น รับออเดอร์แล้ว / กำลังทำ / เสร็จแล้ว) ผ่านหน้าจอเดิม

## Non-functional Requirements

- ใช้งานได้บนเบราว์เซอร์มือถือทั่วไป (iOS Safari, Android Chrome) โดยไม่ต้องติดตั้งแอป
- หน้าเว็บโหลดเร็ว เหมาะกับการใช้งานผ่าน mobile data หรือ wifi ของร้าน
- รองรับลูกค้าหลายโต๊ะสั่งพร้อมกันในเวลาเดียวกันโดยไม่มีออเดอร์สับสนข้ามโต๊ะ

## Business Rules

- QR code 1 อันผูกกับหมายเลขโต๊ะ 1 หมายเลขเสมอ
- คำสั่งซื้อที่ยืนยันแล้ว ลูกค้าไม่สามารถแก้ไข/ยกเลิกเองได้ ต้องแจ้งพนักงานหน้าร้าน

## Scope

**In scope (รอบนี้):**
- เปิดเมนูผ่าน QR code ที่โต๊ะ
- เลือกสินค้า/ตัวเลือก ใส่ตะกร้า ยืนยันคำสั่งซื้อ
- ส่งออเดอร์ไปฝั่งร้านแบบเรียลไทม์ และแสดงสถานะออเดอร์ให้ลูกค้าเห็น

**Out of scope (รอบนี้):**
- การชำระเงินออนไลน์ผ่านระบบ (ยังจ่ายที่เคาน์เตอร์ หรือพนักงานมาเก็บเงินที่โต๊ะ)
- ระบบสมาชิก/สะสมแต้ม
- การสั่งอาหารหรือสินค้าอื่นนอกเหนือจากเครื่องดื่ม

## สมมติฐาน (Assumptions)

- ยังไม่รวมการชำระเงินออนไลน์ในรอบนี้ — ใช้วิธีจ่ายเงินแบบเดิมของร้าน
- ลูกค้าสั่งแบบ guest ไม่ต้อง login หรือสมัครสมาชิกก่อนสั่ง
- แต่ละโต๊ะมี QR code เฉพาะของตัวเองติดถาวรอยู่แล้ว (ไม่ต้องออกแบบขั้นตอนติดตั้ง QR code ใหม่ทุกครั้ง)
